# Assurance Capabilities

This document enumerates capabilities; each capability is authoritative and owns claims and evidence contracts.

Capabilities (canonical list)

- Identity
- Artifact Integrity
- Supply Chain Governance
- Policy Enforcement
- Observability and Forensics
- Registry Governance
- Topology and Networking
- Lifecycle and Rollover

For each capability the canonical pattern is:

- Purpose
- Responsibilities
- Owned claims
- Required Evidence Contracts
- Produced certifications
- Dependencies
- Interfaces
- Extension points

Concrete capability definitions are maintained in capability manifests and must be recorded with an owner in Governance.
