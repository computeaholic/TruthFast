# reports/

Purpose: dated audit, convergence, forensic, and research records retained as
bounded evidence rather than current runtime authority.

What belongs here:

- historical reports
- investigation summaries
- research doctrine and failed-assumption adjudications
- past convergence evidence that is no longer part of the active docs graph
- dated forensic snapshots with explicit review-SHA boundaries

What does not belong here:

- current canonical documentation
- runtime source
- generated build output

Owner: Historical and Research Records

Primary consumers:

- reviewers
- auditors
- maintainers resolving historical questions

Validation entry points:

- markdown link validation
- repository topology validation
