# Contributing

TruthFast is a solo-owned, source-available reference system. Bug reports,
reproduction details, research observations, documentation corrections, and
technical review are welcome through the repository's issue tracker.

External code pull requests are not currently accepted for merge unless the
repository owner separately agrees to the contribution and its terms. An
unsolicited pull request does not create an obligation to review, merge, or
license contributed code. No contributor license agreement is requested by
this policy.

TruthFast repository checks are repository-only. Runtime qualification is a
separate operator-controlled process and must not be inferred from GitHub
Actions. Changes to executable runtime behavior require the corresponding
qualification review before they can be treated as qualified.
